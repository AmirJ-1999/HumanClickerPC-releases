# Human Clicker for PC

Record your mouse clicks, holds and drags once, then let Human Clicker replay them, each time a little
differently, the way a person would.

## Download

**[⬇ Download the latest version](https://github.com/AmirJ-1999/HumanClickerPC-releases/releases/latest)**:
open the newest release and download the `.msi` file under *Assets*.

Needs Windows 10 or 11 (64-bit).

## Install

1. Open the downloaded `HumanClicker-x.y.z.msi`.
2. Windows may show **"Windows protected your PC"**, because the app isn't signed by a paid certificate.
   Click **More info → Run anyway**.
3. It installs in a few seconds without asking for admin rights. Start it from the Start menu or the desktop
   shortcut.

## Updates

Human Clicker checks for new versions by itself and shows an **Update** button when one is out. One click
downloads it, installs it and reopens the app. Your recordings and settings are kept.

## Using it

- **Launch floating bar** puts a small control bar on top of every window, including full-screen games.
- **Record** (red button, or `Ctrl+Alt+R`), use your apps as normal, then stop and name the recording.
  Choose **Full motion** to record every mouse movement too, not only clicks: the most realistic replay.
- **Play** (`Ctrl+Alt+P`) replays it in a loop after a short countdown. **Pause** with `Ctrl+Alt+S`, or just
  click somewhere yourself: playback pauses until you resume.
- **Hotkeys** can be changed to any keys you like (for example F8) under *Hotkeys* in the app.
- **Human feel** modes (Precise, Natural, Relaxed, or your own) decide how much position, path, speed and
  timing vary, with optional short breaks and longer AFK pauses.
- **Export / Import** recordings as files to share them with friends. Files from the Android version work too.

Tips: keep windows where they were when you recorded. Apps running as administrator can only be clicked if
Human Clicker is run as administrator too.

## Privacy

Everything stays on your computer (in `%APPDATA%\Human Clicker`). The app only contacts GitHub to check for
updates. No account, no ads, no data collected.

## Uninstall

Settings → Apps → Installed apps → Human Clicker → Uninstall.

---

Human Clicker is made by AJWorks. Some games don't allow automated input, so check a game's rules before
using it there.
